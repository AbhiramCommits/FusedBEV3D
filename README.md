# FusedBEV3D

Multi-modal (camera + lidar) bird's-eye-view perception stack in PyTorch:
center-based 3D object detection, multi-object tracking and 3-class voxel occupancy,
with a modality-dropout ablation (camera-only / lidar-only / fused).
